description: Импортировать предоставленные PDF правил Trench Crusade в проверяемые Markdown и данные; использовать при замене документов или первичном импорте, а не для обычной разработки интерфейса.
---

Использовать только PDF пользователя. Сначала читать [процедуру импорта](../../../docs/IMPORT.md); путь от корня репозитория — `docs/IMPORT.md`.

Запустить `scripts/import.py --edition <id> --out /tmp/tc-import-<id>` из Python-окружения с `tools/requirements-import.txt`. Для другой редакции передать явный `--manifest`; файл должен описывать именно её PDF и логические разделы. Импорт выполняется в staging, не поверх опубликованных данных.

Скрипт сохраняет шрифтовые выделения, таблицы и страницы; затем группирует сценарии и проверяет сохранность текста/чисел. Его успех не заменяет сверку стоимости, ограничений и многоколоночной вёрстки. Проверять только изменившиеся фрагменты, используя `layout.json`, индекс и страницы PDF. Нечитаемое и неоднозначное отмечать явно. Не переносить механику с Trench Companion.

Для первой редакции `tools/build_catalog.py` детерминированно извлекает базовый каталог из сохранённого layout. Ручные решения хранить только в `catalog-overrides.json`, затем `npm run data:validate`. Для новой редакции пользоваться `tc-add-edition`; старые сопоставления нельзя считать проверенными автоматически.
