name: tc-add-edition
description: Добавить независимую редакцию Trench Crusade или сравнить два подготовленных каталога, сохранив исходные правила и отряды старых редакций.
---

Прочитать `docs/EDITIONS.md`. Создать source manifest для реальных новых PDF; неизвестный номер дополнения оставить null. Импортировать в staging через `tc-import-rules`.

Сопоставить ID сущностей. Сохранять ID одинаковых сущностей, переименование отделять от смены механики. `scripts/compare.py OLD NEW --out /tmp/tc-changes.json` сравнивает каталоги и Markdown без PDF и отдельно выводит текстовые изменения. Ручное сравнение требуется для новых сложных ограничений и нового макета.

Не копировать старые цены или ограничения как проверенные значения. Не создавать демонстрационные редакции в рабочей базе. После схем, ссылок, источников и реальных тестовых отрядов зарегистрировать новую редакцию в registry и генераторе. Привязанные к старой ревизии отряды продолжают использовать её каталог. Выполнить `npm run check` и E2E; убедиться, что `edition-lock.json` старой редакции не изменился.
