description: Проверить схему, связи, источники, ограничения и полноту сохранённой базы Trench Crusade без повторного разбора PDF.
---

Запустить `scripts/check.py` из любого каталога. Скрипт выполняет аудит Markdown и `npm run data:validate`. При изменении игровых механик дополнительно запустить соответствующие доменные тесты.

Для ошибок сначала читать ID и страницу из отчёта, затем нужную сущность и фрагмент Markdown. Схемы находятся в `src/domain/schema.ts`; модель и источники истины описаны в `docs/DATA.md`. Не устранять ошибку ссылок выдуманным значением или понижением severity. Новая неформализованная проверка должна явно давать `manual`, а не успешную валидацию.
