Лаборатория — `trench_graphite_previews_and_css/` (игнорируется Git). Начать с её `README.md`, `gallery.html`, `palettes.json` и прежних материалов. Если каталог отсутствует, создать новую лабораторию, не считать прежние результаты доступными.

- Сохранить `git status` и хеши существующих материалов. Не заменять старую серию: для нового запуска использовать отдельный каталог серии и адаптировать пути скриптов.
- Запускать реальные исходники во временной копии вне репозитория: нужны `src`, `public`, `data`, `reconstruction`, `scripts` и корневые конфиги. Использовать установленные зависимости либо `npm ci` в копии; `npm run dev -- --port 5179` там же. При ссылке на node_modules разрешить Vite доступ к реальному пути зависимостей только в конфиге временной копии, иначе шрифты дают 403.
- Наборы цветов и CSS генерирует `scripts/build_lab.py` в лаборатории; проверить пути и защитить старую серию перед запуском. Применять CSS через `page.addStyleTag`, не редактируя рабочие стили. Два цвета `.hero h1` и `.hero h1 em` обязательны; проверить также навигацию, левую панель, карточки и подписи.
- `scripts/capture.cjs` снимает Chromium 2560×1440, очищает localStorage только временного origin, ждёт шрифты и изображения, отключает анимацию и возвращает страницу наверх. Настроить `TRENCH_LAB` и `TRENCH_URL`; путь к Playwright в автономном запуске адаптировать к копии. Ошибки шрифтов блокируют съёмку. Через Playwright MCP визуально проверить приложение и галерею.
- `scripts/audit_images.cjs` проверяет контраст поверх реальных изображений, `reports/contrast.*` — пары цветов. Отмечать непрошедшие проверки, не выдавать весь эксперимент за доступную тему.
- `python3 scripts/build_gallery.py` обновляет автономную галерею после съёмки. Проверить выбор двух вариантов, разделитель и области; проверить открытие через `file://` обычным Playwright, если MCP блокирует этот протокол. ZIP создавать без включения самого ZIP.

Изображения не изменять; режимы обработки задавать CSS. Все результаты, скрипты и отчёты сохранять в лаборатории. Эксперимент не разрешает менять рабочие компоненты, CSS, зависимости или публиковать изменения. Внедрение выбранной палитры — только по отдельному явному запросу.
