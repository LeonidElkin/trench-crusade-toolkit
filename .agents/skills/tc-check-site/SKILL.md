name: tc-check-site
description: Проверить локальный или опубликованный Trench Crusade Toolkit, включая production base path, E2E и визуальные сценарии браузера.
---

Для приёмки запустить `scripts/check.py`; он выполняет lint, типы, схемы, unit, production build с base `/trench-crusade-toolkit/` и E2E. Для частичного изменения запускать связанные проверки, полный набор перед публикацией.

Через Playwright MCP открыть приложение, дождаться h1 после lazy load и взаимодействовать по accessibility snapshot. Снимки делать после загрузки и scrollTo(0,0); оценивать их глазами. Размеры: 1440×1000, 1280×800, 834×1112, 390×844, 320×740. Проверять меню, таблицы, модальные окна, длинные названия и экипировку. Сценарии уже описаны в `tests/e2e/toolkit.spec.ts`; не повторять их вручную без причины.

Публикация и диагностика: `docs/DEPLOYMENT.md`. GitHub MCP — чтение; запись только Git/gh и только целевой репозиторий. После Actions открыть публичный URL через MCP и выполнить smoke. Успех workflow не заменяет production-проверку. Не выводить токены.
