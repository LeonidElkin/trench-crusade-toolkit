Начать с `scripts/check.py --edition 1.6.3`; он показывает отсутствующие и общие изображения по стабильным ID. Устройство файлов и команды — в `docs/ILLUSTRATIONS.md` от корня репозитория. Не перечитывать весь корпус правил.

Сначала проверить существующий индекс и предоставленные PDF, затем подходящие оригинальные изображения в интернете; сохранить автора и URL. Хорошие изображения не заменять. Для недостающих применять системный Skill `imagegen` и именно встроенный `image_gen`; без API-ключей, CLI платного API или обходов через аккаунты. Если инструмент недоступен, сохранить список отсутствующих изображений и продолжать независимые задачи.

Промпт составлять из адресного Markdown/профиля нужной редакции: внешний вид, фракция, обязательная или допустимая экипировка. Не придумывать характеристики и вооружение. Для портретов — один персонаж целиком, единая сдержанная grimdark-палитра и композиция, без текста. Для других иллюстраций согласовать композицию с назначением, сохранив направление. Пользовательское разрешение охватывает любые иллюстрации сайта.

Сохранить полный промпт до вызова. Проверить результат визуально. Для бойца скопировать и зарегистрировать результат через `tools/manage-portraits.ts add-generated`; скрипт сохраняет оригинал, WebP и стабильную связь. Не вызывать генерацию повторно, если подходящий оригинал уже сохранён. Другие иллюстрации хранить с таким же происхождением и промптом, без искусственного fighter ID.

Завершить `npm run data:validate`, E2E и визуальной проверкой затронутых компонентов через Playwright MCP. Уточнения художественного образа не должны менять замороженные игровые данные.
