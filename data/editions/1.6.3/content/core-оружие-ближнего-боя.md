## Оружие ближнего боя

| Предмет | Стоимость и ограничения |
| --- | --- |
| Окопный нож | 1 дукат |
| Штык | 2 дуката (Совместим с щитом) |
| Окопная Дубинка | 3 дуката |
| Меч/топор | 4 дуката |
| Древковое оружие | 7 дукатов (Совместим с щитом) |
| Большой молот/кувалда | 10 дукатов |
| Большой меч/топор | 12 дукатов |
| Жертвенный нож | 23 дуката ( **Лимит: 2**, **только для Элиты** ) |
| Адский меч | 1 очко славы ( **Лимит: 2** ) |
| Когти Тартара | 15 дукатов (только для Коммандоса Смерти) |
| Богохульный посох | 2 очка славы ( **Только для Элиты** ) |
