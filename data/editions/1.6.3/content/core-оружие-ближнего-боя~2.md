## Оружие ближнего боя

| Предмет | Стоимость и ограничения |
| --- | --- |
| Окопный нож | 1 дукат |
| Штык | 2 дуката (Совместим с щитом) |
| Окопная Дубинка | 3 дуката |
| Меч/топор | 4 дуката |
| Цеп/плеть | 5 дукатов |
| Древковое оружие | 10 дукатов (Совместим с щитом) |
| Большой молот/кувалда | 10 дукатов |
| Большой меч/топор | 12 дукатов |
| Противотанковый молот | 35 дукатов ( **Только для Элиты**, **Лимит: 3** ) |
| Милосердие | 15 дукатов ( **Лимит: 1** ) |
