## Оружие ближнего боя

| Предмет | Стоимость и ограничения |
| --- | --- |
| Окопный нож | 1 дукат |
| Штык | 2 дуката (совместим с щитом) |
| Окопная Дубинка | 3 дуката |
| Меч/топор | 4 дуката |
| Древковое оружие | 7 дукатов (Только для Чумного Рыцаря, совместим с щитом) |
| Большой молот/кувалда | 10 дукатов |
| Большой меч/топор | 12 дукатов |
| Чумной клинок | 7 дукатов ( **Лимит: 2**, **только для Элиты** ) |
| Топор Вельзевула | 30 дукатов ( **Лимит: 1**, **только для Элиты** ) |
