## Снаряжение

| Предмет | Стоимость и ограничения |
| --- | --- |
| Боевой шлем | 5 дукатов |
| Противогаз | 5 дукатов |
| Лопата | 5 дукатов (только для Иго-Демонов и Несчастных) |
| Нечестивый амулет | 15 дукатов ( **CONSUMABLE** ) |
| Нечестивая реликвия | 15 дукатов |
| Зажигательные боеприпасы | 15 дукатов ( **Лимит: 1**, **CONSUMABLE** ) |
| Знамя | 1 Очко Славы ( **Лимит: 1** ) |
| Музыкальный инструмент | 15 дукатов ( **Лимит:1** ) |
| Корона Адского Пламени | 15 дукатов ( **только для Элиты** и Ямной Саранчи) |
| Узда подчинения | 10 дукатов (Только для Иго-Демонов, **Лимит: 3** ) |
