# Снайперский прицел (Sniper Scope)

*Эти оптические прицельные устройства популярны среди снайперов для прицеливания на больших дистанциях*.

**Правила:** Нейтрализует штраф за дальнюю дистанцию, если модель не двигалась во время этой Активации. Используется только с винтовками (то есть с оружием, имеющим в названии ключевое слово “винтовка”).
