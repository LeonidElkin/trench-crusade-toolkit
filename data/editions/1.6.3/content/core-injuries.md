# Таблица ранений

Если ваша атака попадает по врагу, следующим шагом будет определение урона, нанесённого атакой. Бросьте **2D6** (плюс любые модификаторы **+/-DICE** из профиля модели или других источников), выберите два самых больших результата (или два наименьших, если были применены **-DICE**) и обратитесь к следующей таблице:

| Результат | Ранение |
| --- | --- |
| 1 (или меньше) | Без эффекта |
| 2–6 | Лёгкое ранение |
| 7–8 | Повален |
| 9+ | Выведен из строя (Out of Action) |

**Примечание:** Иногда правило может требовать бросить больше (или меньше) чем 2D6, чтобы определить результат броска. Если бросок модифицирован **+/- DICE**, модифицируйте пул кубиков как обычно и оставьте количество кубиков, равное числу кубиков в изначальном пуле. Например, если правило требует бросить 3D6 с **+1 DICE**, вы бросаете четыре кубика и выбираете три самых больгих результата.

**Модификаторы к броскам на таблице ранений:**

**Траншейный щит (Trench Shield):** -1 к броскам на ранения (может быть совмещён с любой бронёй).

**Стандартная броня (Standard Armour):** -1 к броскам на ранение.

**Усиленная броня (Reinforced Armour):** -2 к броскам на ранение.

**Механизированная броня (Machine Armour):** -3 к броскам на ранение (не совмещается с щитом).

**Цель в состоянии "Повален":** Добавьте **+1 DICE** к пулу кубиков при определении ранений для модели, которая находится в состоянии "Повален".

**Без эффекта:** Броня цели выдерживает удар. Никакого эффекта.

**Лёгкое ранение:** Добавьте **+1 Маркер Крови** рядом с моделью для обозначения ранения. Используйте точки на кубике для подсчёта ранений (максимум шесть на модель).

Всякий раз, когда раненая модель выполняет **ДЕЙСТВИЕ**, оппонент может потратить один или несколько её **Маркеров Крови**, чтобы добавить **-1 DICE** за каждый потраченный маркер.

При броске на ранение против этой модели оппонент может потратить маркеры крови, чтобы добавить **+1 DICE** за каждый потраченный маркер.

При атаке раненой модели можно потратить Маркеры Крови для добавления **+1 DICE** за каждый маркер.

**Боец повален!** Добавьте **+1 Маркер Крови** рядом с моделью, и модель становится "Поваленной". Если модель уже находится в состоянии "Повален", она получает **+2 Маркера Крови** и остаётся в этом состоянии.

Модель в состоянии "Повален" получает штраф **-1 DICE** ко всем её **ДЕЙСТВИЯМ** и не может двигаться самостоятельно.

Чтобы отметить состояние "Повален", можно использовать индикатор рядом с моделью или положить модель набок.

В начале активации "Поваленный" воин может встать. Но все перемещения (Движение, Рывок, Нападение, Прыжок и т. д.) модели сокращаются наполовину. Если модель становится "Поваленной" во время своей активации, она может выполнить **рискованное действие**, чтобы встать. Иначе она остаётся в состоянии "Повален" до конца активации.

**Выведен из строя:** Воин получает серьёзное ранение и выбывает из игры до конца битвы. Уберите модель с игрового поля. Разрешите, что случилось с моделью после битвы, следуя разделу о серьёзных ранениях в правилах.
