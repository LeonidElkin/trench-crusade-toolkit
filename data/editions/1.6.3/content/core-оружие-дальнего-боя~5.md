## Оружие дальнего боя

| Предмет | Стоимость и ограничения |
| --- | --- |
| Винтовка | 10 дукатов (Штыковое крепление) |
| Пистолет | 6 дукатов |
| Мушкет | 5 дукатов (Штыковое крепление) |
| Зараженная винтовка | 15 дукатов (Штыковое крепление) |
| Извергающий заразу | 30 дукатов ( **Лимит: 2** ) |
| Пулемёт | 50 дукатов (Только для Амальгамы, **Лимит:1** ) |
| Дробовик | 10 дукатов (Штыковое крепление, совместим с щитом) |
| Гнилостный дробовик | 20 дукатов ( **Лимит: 2** , Штыковое крепление, совместимость со щитом) |
| Газовые гранаты | 10 дукатов |
| Паразитические гранаты | 15 дукатов |
| Пушка внутренностей | 50 дукатов ( **Лимит: 1**, **только для Элиты** ) |
