## Оружие ближнего боя

| Предмет | Стоимость и ограничения |
| --- | --- |
| Траншейный нож | 1 дукат |
| Штык | 2 дуката (Совместим с щитом) |
| Окопная Дубинка | 3 дуката |
| Меч/Топор | 4 дуката |
| Древковое оружие | 7 дукатов (Совместим с щитом) |
| Алебарда-пушка | 20 дукатов ( **Только для Элиты** ) |
| Большой молот/Кувалда | 10 дукатов |
| Большой меч или топор | 12 дукатов |
| Титан Зульфикар | 30 дукатов (Только для Бронзового Быка) |
| Кинжал Ассасина | 15 дукатов (Только для Ассасинов) |
