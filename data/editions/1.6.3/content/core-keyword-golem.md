# **GOLEM**

**GOLEM**: Эта модель — Голем, созданный на основе утраченных каббалистических знаний, и её крайне трудно уничтожить. Она рассматривает результат ранения **"Выведен из строя"** как **"Повален"**, если только атака не была совершена с использованием правила **"Кровавая баня"** – в этом случае результат **"Выведен из строя"** удаляет модель с поля боя, как обычно. Голем не получает дополнительных **Маркеров Крови** от оружия с ключевым словом **GAS** и не подвержен эффекту ключевого слова **FEAR**. Игрок, контролирующий Голема, не может удалять с него **Маркеры Крови** никакими способами, однако его оппонент может использовать их по стандартным правилам.
