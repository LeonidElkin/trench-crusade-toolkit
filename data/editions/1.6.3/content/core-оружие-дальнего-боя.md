## Оружие дальнего боя

| Предмет | Стоимость и ограничения |
| --- | --- |
| Винтовка | 10 дукатов (Штыковое крепление) |
| Полуавтоматическая винтовка | 15 дукатов (Штыковое крепление) |
| Автоматическая винтовка | 2 очка славы ( **Лимит: 2** , Штыковое крепление) |
| Пистолет | 6 дукатов |
| Пистолет с глушителем | 15 дукатов ( **Только для Элиты** ) |
| Граната | 7 дукатов |
| Газовая граната | 10 дукатов |
| Зажигательная граната | 15 дукатов |
| Пистолет-пулемёт | 2 очка славы (Штыковое крепление, совместим с щитом) |
| Дробовик | 10 дукатов (Штыковое крепление, совместим с щитом) |
| Автоматический дробовик | 15 дукатов (Штыковое крепление, совместим с щитом) |
| Гранатомёт | 30 дукатов ( **Лимит: 2** ) |
| Пулемёт | 50 дукатов ( **Лимит: 1** ) |
| Огнемёт | 30 дукатов ( **Лимит: 3** ) |
| Тяжёлый огнемёт | 55 дукатов ( **Лимит: 2** ) |
| Противотанковая винтовка | 3 очка славы ( **Лимит: 1** ) |
