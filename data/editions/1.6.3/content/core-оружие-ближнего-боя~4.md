## Оружие ближнего боя

| Предмет | Стоимость и ограничения |
| --- | --- |
| Окопный нож | 1 дукат |
| Штык | 2 дуката (совместим с щитом) |
| Окопная Дубинка | 3 дуката |
| Меч/топор | 4 дуката |
| Древковое оружие | 7 дукатов (совместим с щитом) |
| Большой молот/кувалда | 10 дукатов |
| Большой меч/топор | 12 дукатов |
| Мизерикордия | 15 дукатов ( **Лимит: 1** , только для Боевого медика) |
