## Снаряжение

| Предмет | Стоимость и ограничения |
| --- | --- |
| Боевой шлем | 5 дукатов |
| Противогаз | 5 дукатов |
| Нечестивый талисман | 15 дукатов ( **CONSUMABLE** ) |
| Нечестивая реликвия | 15 дукатов |
| Зажигательные боеприпасы | 15 дукатов ( **Лимит: 1**, **CONSUMABLE** ) |
| Лопата | 5 дукатов |
| Адское Клеймо | 5 дукатов |
| Боевой флаг | 1 очко славы ( **Лимит: 1** ) |
| Музыкальный инструмент | 15 дукатов ( **Лимит: 1** ) |
| Альпинистский комплект | 3 дуката ( **Лимит: 2** ) |
| Контракт с Адом | 5 дукатов ( **Лимит: 3** , только для Пехоты Еретиков и Легионеров) |
