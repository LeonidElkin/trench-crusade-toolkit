# Редакции и ревизии

Сейчас зарегистрирована только 1.6.3, ревизия `ru-1.6.3-r1`. Дополнение не имеет собственного указанного номера. Пустые/фиктивные редакции в приложении не создаются.

Каждый установленный каталог имеет собственные ID редакции, ревизию, source manifest и схемы. Stable entity ID идентифицирует ту же сущность между редакциями; изменившийся перевод названия сам по себе не должен менять ID. Явные переименования/разделения отражать в таблице сопоставления при реальной миграции.

`getEdition(id, revision)` возвращает только точное совпадение при указанной ревизии. Отряды хранят эту пару. Изменения цены, оснащения и состава не применяются к старому отряду автоматически. Неизвестный каталог остаётся доступен для экспорта без вычисления по другим правилам.

## Новая реальная редакция

1. Получить PDF и создать явный manifest со своими логическими разделами и метаданными источников.
2. Импортировать в staging через проектный Skill. Проверить таблицы, профили и ограничения. Не считать старые overrides проверенными для новой редакции.
3. Сохранить новый каталог в отдельном каталоге, сопоставить ID и выполнить `tc-add-edition/scripts/compare.py`.
4. В отчёте разделить изменения текста/названия и механических полей. Это сравнение данных, не автоматическая интерпретация всей прозы: новые неформальные правила требуют ревью.
5. Добавить явную регистрацию нового набора в генератор и registry/content loader. Компоненты билдера получают закреплённый каталог; доменные функции принимают каталог аргументом. Для изменившихся таблиц вероятностей передать соответствующий classifier, не использовать механику 1.6.3 молча.
6. Запустить старые и новые фикстуры, импорт/экспорт, проверку старого edition-lock и E2E. Старые документы/каталог не менять.

Схемы каталога и экспорта имеют отдельный `schemaVersion`. Изменение интерфейса не должно менять экспортный формат. Миграцию отряда реализовывать как явное копирование с отчётом потерь/замен, а не изменением сохранённого исходника. Раздел «Что изменилось» появится при наличии второй реальной редакции; сейчас его нет.
