# Редакции и ревизии

Зарегистрирована только редакция1.6.3, revision `ru-1.6.3-visual-r2`. У дополнения собственного указанного номера нет. Фиктивных редакций нет.

Для этой реконструкции пользователь явно разрешил полностью заменить недостоверную первую ревизию и отказаться от совместимости с её отрядами. Первая версия сохранена в Git-теге `backup/pre-visual-reconstruction-2026-11-11`, в runtime она не используется. Формат v1 отклоняется с объяснением; автоматической миграции нет.

Для будущей реальной редакции создать отдельный source manifest, авторские записи и независимые постраничные reviews. Старые цены, ограничения и Markdown не заполняют новый импорт. Допускается сравнивать уже подготовленные каталоги после независимого восстановления. Skill `tc-add-edition/scripts/compare.py` сравнивает v2 `catalog.json` и Markdown либо полный `edition.json`, не смешивая слои overrides.

`getEdition(id, revision)` должен выбирать точный зарегистрированный набор. Новые редакции регистрируются явно в генераторе/registry и content loader; доменные функции получают свой каталог. Разные редакции и старые отряды не мигрируются автоматически. Изменение правил не подставляется незаметно в сохранённый отряд.

Перед регистрацией: полный допуск покрытия, схемы/ссылки, source-backed ограничения, реальные сценарии билдера, unit/data/build/E2E, Playwright MCP и контроль старых frozen-наборов. Сравнение каталога не интерпретирует прозу и не доказывает правильность PDF-импорта. Процедура импорта: `docs/IMPORT.md`.
