# Воспроизводимый импорт PDF

Обычный `npm run dev`, тесты, CI и сборка не разбирают PDF. Этот процесс нужен только при явном импорте. Опубликованные источники перевода Мастерской Кетсу находятся в `public/reference/`; пути заданы полем `path` в манифесте импорта, оригинальные имена и SHA сохранены в метаданных. При добавлении источника без `path` используется `reference/<filename>` относительно корня репозитория.

```sh
python3 -m venv /tmp/tc-import-venv
/tmp/tc-import-venv/bin/pip install -r tools/requirements-import.txt
/tmp/tc-import-venv/bin/python .agents/skills/tc-import-rules/scripts/import.py \
  --edition 1.6.3 --out /tmp/tc-import-1.6.3
```

Manifest: `tools/import-manifests/1.6.3.json`. Он задаёт реальные источники, их редакции и диапазоны логических разделов, а не страничную структуру сайта. Для нового документа создать новый manifest и передать `--manifest`; номер дополнения нельзя выдумывать. Staging должен быть пустым. Wrapper запрещает запись поверх `data/editions/`.

## Обработка

1. PyMuPDF 1.26.7 сохраняет текстовые блоки, координаты и стили. Исключаются колонтитулы; порядок текстовых колонок сохраняется.
2. Таблицы без рамок восстанавливаются по координатам заголовков и пересекающимся фрагментам. Ценовые таблицы имеют отдельный геометрический парсер, поскольку Word мог разнести цену и название по блокам.
3. Термины сохраняют язык/выделение. Заголовки объединяют визуальные переносы. Сценарии собираются в логические документы; схемы из разрешённых исходников прикрепляются отдельно.
4. `tools/audit_content.py` сравнивает мультимножества букв/цифр и числовых токенов сохранённого layout с Markdown по каждой странице. 160 страниц содержат извлекаемый текст; остальные 30 учтены в общем 190-страничном отчёте как иллюстрации/служебные страницы.
5. Для текущей редакции `tools/build_catalog.py` создаёт базовые профили, предметы, предложения, варианты и ключевые слова. Он откажется продолжать при несовпадении ожидаемого количества профилей. Не переносить эту интерпретацию на другую редакцию без ревью.
6. Проверенные уточнения хранятся в `catalog-overrides.json`: это рабочий ручной слой, его нельзя перегенерировать догадками. Проверяются схемы/ссылки, затем реальные контрольные отряды и браузер.

Воспроизводимость проверяется сравнением staging с текущей базой. Отсутствующий текст не восстанавливать по знаниям игры. Ключевые риски: неверная привязка похожих названий, краткие ссылки варианта на полный профиль, условные ключевые слова в таблицах и разрывы между профилями.

`tools/extract_assets.py` — отдельная явная процедура для известных иллюстраций/схем текущего PDF. Manifest `data/assets.json` хранит страницу, xref и checksum каждого файла. Пользователь разрешил публикацию текстов и изображений 2026-11-10. Для других PDF не использовать старые xref и карты.

Аудит 100% сохранности символов относительно извлечения не заменяет визуальную проверку PDF и не доказывает полноту извлечения из растровой страницы. В текущих источниках страницы с отсутствующим текстом просмотрены как иллюстрации; OCR-механики по догадкам не добавлялись.
