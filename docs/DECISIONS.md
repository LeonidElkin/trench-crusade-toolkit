# Принятые решения

1. **React + TypeScript strict + Vite.** Простая статическая сборка, поддерживаемые библиотеки, типизируемая доменная логика. SSR/бэкенд не нужны.
2. **Hash-маршруты.** Глубокие ссылки открываются на GitHub Pages без обходных 404-редиректов и привязки бизнес-логики к deployment.
3. **Markdown + каталог + overrides.** Тексты редактируются отдельно от характеристик; один механизм компиляции соединяет их. Не хранить независимые описания в UI.
4. **Zod на границах.** Импортированный отряд и игровая база проверяются до использования. Структурно допустимый отряд отдельно проверяется на игровые ограничения.
5. **Диагностика вместо запрета.** Ошибки и непроверенные условия видны; временный состав можно сохранить. Сложные правила реализуются доменными функциями, не обработчиками компонентов.
6. **Целочисленная математика.** Распределение по мультимножествам граней с точными мультиномиальными коэффициентами. Нет Monte Carlo; дополнительная свёртка для суммируемых кубиков. Независимый полный перебор малых пулов служит тестовым оракулом.
7. **localStorage v1.** Размер обычных отрядов мал, асинхронная IndexedDB пока избыточна. Ошибка записи видна, JSON переносим, повреждение не перезаписывается молча.
8. **Редакция + ревизия в отряде.** Цена не зависит от «последней» версии. Новые редакции регистрируются явно.
9. **Локальные шрифты и изображения.** Нет обязательных внешних CDN/трекеров. Визуальный стиль — полевой архив с приглушёнными цветами и читаемыми текстами.
10. **GitHub Actions → Pages.** Бесплатно, без обслуживания сервера. Деплой возможен только после проверок; production smoke проверяет реальный публичный адрес.
