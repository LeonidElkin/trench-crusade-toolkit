Дальнейшие улучшения: редакторская сверка остальных редких условий, расширение специализированных валидаторов, реальная следующая редакция при наличии PDF. Сайт работает; облачная синхронизация/PWA/кампанийный менеджер не реализованы и не требовались для текущего статического продукта.

Покрытие 66/66 без общих сопоставлений проверяет `tc-illustrations/scripts/check.py --check`; все промпты и оригиналы сохранены. Для обновления пройдены полный `npm run check` (32 tests) и E2E 13 passed / 1 deliberately skipped; проверены пять viewport, source provenance и восстановление обзора после reload.
