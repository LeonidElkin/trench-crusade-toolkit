- Справочник, поиск/закладки, фракции, точный калькулятор, билдер, диагностика, localStorage, дублирование, JSON и ссылки. Контекстные правила и схемы; локальные шрифты/иллюстрации.
- Документация в docs и четыре проверяемых Skill в `.agents/skills/`.
- Workflow Pages с закреплёнными SHA, проверками и production smoke. Публикацию ещё надо подтвердить.
