# Данные правил

Первичные редакторские записи находятся в `reconstruction/1.6.3/authored/`. Они созданы заново по двум оригинальным PDF и содержат полные тексты, структурированные сущности, координаты/страницы и постраничные решения. Независимые подтверждения находятся в `reviews/`; `manifest.json` закрепляет SHA оригиналов, `links.json` хранит явные сопоставления названий, `integration-issues.json` — выявленные при интеграции противоречия.

`npm run data:compile` проверяет все190страниц, автора и другого проверяющего, SHA исходных PDF, авторских файлов и текста, затем формирует только новую revision `ru-1.6.3-visual-r2`. Входов `catalog-base`, overrides, старого layout или скрытых fallback нет. Текст первичен в авторском JSON; Markdown и runtime JSON генерируются, а не редактируются независимо.

`node --import tsx scripts/export-reconstruction.ts` явно пересоздаёт производный `data/editions/1.6.3/`: `content/*.md`, `articles.json`, `catalog.json`, `sources.json`, `coverage.json`, `issues.json`, `inputs.json` и `edition-lock.json`. Экспорт разрешён только после полного допуска. Старое состояние восстановимо через Git-тег `backup/pre-visual-reconstruction-2026-11-11`.

Каталог schema2 разделяет предмет и предложение арсенала: у предложения собственные стоимость, валюты, лимит и доступ. Дукаты и Слава независимы. Профили включают неснимаемые предметы, явное наследование, способности, наборы и условия; варианты применяют подтверждённые изменения состава и экипировки. Полные новые записи сохраняются в `definition`, источник — в `source` до таблицы/блока. Неизвестные свойства остаются `null` и дают ручную проверку, а не вымышленное значение.

Одноимённые предметы из разных разделов не объединяются по английскому названию. Сопоставления кратких названий видимы в `links.json`; допущения и неразрешённые связи не считаются доказанными. Исходные опечатки и противоречия сохранены; список в `docs/KNOWN-ISSUES.md`.

Схемы: `src/domain/schema.ts`. Проверки: `scripts/validate-data.ts`, доменные тесты, постраничный gate и отрицательные тесты импорта. Они дополняют реальную визуальную сверку, не заменяют её. Формат отрядов/envelope/export/localStorage — v2; v1 не мигрируется и не перезаписывается автоматически.
