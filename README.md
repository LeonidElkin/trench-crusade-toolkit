# Trench Crusade Toolkit

**Некоммерческий, бесплатный и неофициальный проект сообщества.** Русский статический компаньон Trench Crusade редакции 1.6.3: интерактивный справочник, точный калькулятор вероятностей и варбанд-билдер.

**Проект целиком и полностью разрабатывается с помощью AI-агентов:** архитектура, программный код, подготовка данных, тесты, документация и публикация. Игровые правила, русский перевод и исходные иллюстрации созданы их авторами и правообладателями.

[Открыть сайт](https://leonidelkin.github.io/trench-crusade-toolkit/) · [Состояние проверок](https://github.com/LeonidElkin/trench-crusade-toolkit/actions) · [Сообщить об ошибке](https://github.com/LeonidElkin/trench-crusade-toolkit/issues)

## Возможности

- Все предоставленные русские правила и дополнение «Союзники и наёмники», поиск, ключевые слова, таблицы, ссылки, закладки и схемы сценариев.
- Точные вероятности действий и ранений: отдельные DICE и фиксированные модификаторы, их компенсация, специальные исходные пулы и дополнительные кубики.
- Шесть фракций и четырнадцать вариантов. Бойцы, неснимаемая экипировка, специальные арсеналы, улучшения, гоэтические силы, дукаты и Очки Славы.
- Диагностика обязательного состава, лимитов и совместимости. Временно невалидные отряды допускаются; непроверяемые условия отмечены явно.
- Несколько отрядов в браузере, автоматическое сохранение, дублирование, экспорт/импорт JSON и обмен по ссылке. Авторизация и сервер не нужны.
- Адаптивный интерфейс, собственные шрифты и ресурсы, статическая публикация через GitHub Actions.

## Локальный запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Открыть адрес Vite, обычно http://localhost:5173/. Обычная разработка и сборка используют сохранённые Markdown/JSON и **не читают PDF**.

```sh
npm run check
npx playwright install chromium
APP_BASE_PATH=/trench-crusade-toolkit/ npm run build
npm run test:e2e
```

`npm run check` выполняет линтер, TypeScript, валидацию игровой базы, unit-тесты и сборку. E2E проверяет production-сборку с настоящим base path GitHub Pages. Для проверки существующего сайта: `E2E_BASE_URL=https://leonidelkin.github.io/trench-crusade-toolkit/ npm run test:e2e`.

## Данные и точность

Единственные источники игровых механик — **русский перевод Мастерской Кетсу**, сохранённый в репозитории:

- [Основные правила Trench Crusade 1.6.3 (PDF)](public/reference/trench-crusade-1.6.3-ru.pdf).
- [«Союзники и наёмники» (PDF)](public/reference/allies-and-mercenaries-ru.pdf); номер редакции в документе не указан.

Trench Companion использован как референс интерфейса; его игровые данные не использовались.

Текст хранится в `data/editions/1.6.3/content/`, характеристики — в `catalog-base.json`, проверенные уточнения извлечения и сложные ограничения — в `catalog-overrides.json`. Производные файлы генерируются автоматически. У сущностей есть страницы источника и стабильные ID.

Выполнены автоматическое извлечение всех 190 страниц, восстановление таблиц, сверка сохранности текста и чисел и выборочная ручная проверка критических профилей. Это не постраничная редакторская корректура. В источнике есть неоднозначности и опечатки; они сохранены и описаны в [известных ограничениях](docs/KNOWN-ISSUES.md). Сообщение «Нужна сверка» означает, что правило не подтверждено автоматически. Отсутствие ошибок не означает полную игровую валидность.

Отряды привязаны к редакции и ревизии. Новые редакции не должны автоматически менять старые отряды. Данные хранятся только на устройстве пользователя: сохраняйте JSON-копии перед очисткой браузера.
